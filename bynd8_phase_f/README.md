# BYND8 Phase F — Cursor Handoff

This package contains the Phase F visual redesign prompt and directional UI references for the organizer experience.

## Start here

Give Cursor `PHASE-F-CURSOR-PROMPT.md` and make the `reference-ui/` folder available in the repo/workspace so it can inspect the images.

## Important

The images are visual references, not pixel-perfect specifications. Existing Phase A–E functionality and real API contracts are authoritative.
